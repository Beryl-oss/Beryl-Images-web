# 🎨 Béryl Images — Style Guide

> **Version:** 1.0
> **Last Updated:** July 2026

---

# ✨ Brand Philosophy

**Béryl Images** is built around one simple idea:

> **Create digital experiences that feel elegant, intentional, and memorable.**

Every visual element should communicate professionalism, clarity, and attention to detail.

---

# 🎯 Design Principles

### Simplicity

Avoid unnecessary complexity. Every element must have a purpose.

### Consistency

Colors, spacing, typography, and animations should always follow the same visual language.

### Performance

Beautiful interfaces should also be fast.

### Accessibility

Designs should remain readable and usable for everyone.

### Premium Feel

Every interaction should feel smooth, polished, and carefully crafted.

# Spacing

Use an 8px spacing system whenever possible.

Examples:

```
8px
16px
24px
32px
48px
64px
96px
```

This creates visual consistency across the interface.

---

# Border Radius

Preferred values:

```
8px
12px
16px
24px
```

Avoid excessively rounded components unless intentionally designed.

---

# Shadows

Shadows should remain subtle.

The goal is depth—not distraction.

---

# Buttons

Primary Button

* Deep Blue background
* White text
* Smooth hover transition

Secondary Button

* Transparent background
* Colored border
* Accent hover

Buttons should never feel heavy.

---

# Icons

Preferred style:

* Minimal
* Outline
* Consistent stroke width

Avoid mixing icon families.

---

# Images

Images should always be:

* High resolution
* Well cropped
* Properly optimized
* Modern (WebP when possible)

Avoid blurry or stretched assets.

---

# Animations

Animations should enhance—not interrupt.

Preferred library:

```
GSAP
```

Guidelines:

* Smooth
* Natural
* Short duration
* Meaningful

Avoid excessive motion.

---

# Responsive Design

The experience should remain excellent on:

* Mobile
* Tablet
* Desktop

Never sacrifice usability for aesthetics.

---

# Code Style

Keep components:

* Small
* Reusable
* Well named

Prefer composition over duplication.

Folder names should remain consistent throughout the project.

---

# Accessibility

Always verify:

* Readable contrast
* Keyboard navigation
* Semantic HTML
* Alt text for images

Accessibility is part of quality.

---

# Performance

Prioritize:

* Lazy loading
* Image optimization
* Clean code
* Efficient animations

A fast website is part of the design.

---

# Brand Voice

The visual identity should communicate:

* Professionalism
* Creativity
* Precision
* Confidence
* Elegance

Never flashy.

Always intentional.

---

# Inspiration

The visual direction of Béryl Images draws inspiration from:

* Apple
* Stripe
* Linear
* Framer
* Vercel

Not to imitate them—but to pursue the same level of clarity and refinement.

---

# Final Rule

Every design decision should answer one question:

> **Does this make the experience clearer, more beautiful, or more useful?**

If the answer is **no**, it probably doesn't belong.
